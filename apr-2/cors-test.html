DeepSeek API 直连 CORS 自检

这是方案里"步骤 0"的独立验证页面：在把整套 demo 部署到 GitHub Pages 之前， 先确认浏览器能否从当前域名直接调用 DeepSeek 的 chat completions 接口。 这个页面只做一次最简调用，不涉及 demo 的其余逻辑。

怎么判断结果：如果按钮点击后 5~10 秒内看到绿色的"直连成功"，说明 GitHub Pages 方案可行， 直接用 index.html 即可。如果看到红色报错，且浏览器控制台（F12 → Console）出现 has been blocked by CORS policy 字样，说明 DeepSeek 不允许浏览器直连， 需要按 README 里的"CORS 不通怎么办"一节加一层代理再演示。
